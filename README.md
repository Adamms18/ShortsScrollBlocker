# Shorts Scroll Blocker

Simple and minimalist browser extension that disables scrolling on Youtube Shorts.

Got fed up with brainless scrolling and wrote it in 15 mins.

## Features
* Doesn't turn off shorts completely, you can still watch the videos that interest you.
* Blocks you from scrolling to the next video.
* Hides the preview for the next video at the bottom.
* As simple as it can be.
* Take back your time and reclaim your attention.
